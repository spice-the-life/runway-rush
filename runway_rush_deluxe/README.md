# Runway Rush — Deluxe fashion prototype

A static HTML/CSS/JavaScript fashion dress-up prototype.

## Features
- Expanded outfit options and color palettes
- Multiple hairstyles and hair colors
- Handbag, necklace, earrings, glasses, hat, and fairy wings
- Fabric patterns and themed looks
- Runway challenge themes with a two-minute styling timer

## Deploy on Render
Create a **Static Site** from this repository. Set **Publish Directory** to `public`. Leave the build command blank. The repository root should contain `public/index.html` and `README.md`.

This remains a single-player prototype. The runway timer and theme prompt are implemented, but real multiplayer, voting, and server-synchronized rounds are not included yet.

# Runway Rush — lightweight safe-source version

This version contains only a static HTML page with CSS and JavaScript. It has no executable installers, no server-side scripts, and no package dependencies.

## Preview locally
Open `public/index.html` in a browser.

## Deploy on Render
Create a **Static Site** from your GitHub repository. Set **Publish Directory** to `public`. No build command is needed.

This is a visual prototype, not a finished multiplayer game. It does not currently include multiplayer rooms, timed rounds, or voting. It uses CSS-drawn character art rather than downloaded model files.
